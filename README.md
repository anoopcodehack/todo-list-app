Todo List Web App

A simple, fast, and clean Todo List website that helps users add, manage, and track daily tasks. Built with a focus on usability, minimalism, and smooth interaction.

 Features-

Add new tasks instantly

Mark tasks as complete

Delete tasks you no longer need

Edit existing tasks

Tasks saved in localStorage (they stay even after refresh)

Fully responsive UI

Clean, simple layout
Technologies Used-

HTML5

CSS3

JavaScript (Vanilla)
